## 1. Português

### 1.1 Curso em Vídeo — Banco de Dados MySQL 🎓 🇧🇷

- **Autor:** Gustavo Guanabara
- **Onde:** <https://www.cursoemvideo.com/curso/mysql/> · também no YouTube
- **Duração:** anunciada como 40 h (a versão original tinha ~6 h de vídeo)
- **Nível:** zero absoluto → intermediário
- **Certificado:** **gratuito**, mediante cadastro no site
- **Vale?** **Sim, para quem nunca viu banco de dados.** É o curso de SQL em
  português mais assistido do Brasil, e a didática do Guanabara é a razão. Ele
  começa em "o que é uma tabela" e chega a `JOIN` e subconsultas.
- **Ressalvas honestas:** é sobre **MySQL**, com phpMyAdmin — não é o dialeto
  deste curso, e o MySQL tem permissividades que ensinam hábitos ruins (aspas
  duplas para texto, coluna fora do `GROUP BY`). O material é de 2016, com
  atualizações; a parte de instalação está datada. **Aprenda os conceitos, e
  volte aqui para o dialeto.**

### 1.2 Programação Dinâmica — SQL para Análise de Dados 💰 🇧🇷

- **Autor:** Hallison Paz e equipe
- **Onde:** <https://www.youtube.com/playlist?list=PL5TJqBvpXQv5n1N15kcK1m9oKJm_cv-m6>
  · material e exercícios em <https://github.com/programacaodinamica/sql-analise-dados>
- **Nível:** iniciante → intermediário
- **Vale?** **Sim, e é a minha primeira recomendação em português para quem
  quer usar SQL para analisar dados** (que é o seu caso, se você é engenheiro).
  Foco em consulta analítica, não em administração de banco. O repositório com
  exercícios no GitHub é o diferencial: você pratica, não só assiste.
- **Ressalva:** pressupõe alguma familiaridade com terminal.

### 1.3 Hashtag Treinamentos — Curso Básico de SQL 💰 🇧🇷

- **Onde:** <https://www.hashtagtreinamentos.com/curso-basico-de-sql> e YouTube
- **Duração:** 6 aulas
- **Vale?** Como primeiro contato rápido, sim. É um funil comercial para cursos
  pagos — o que não invalida o conteúdo gratuito, mas saiba disso.

### 1.4 Documentação oficial em português

- **PostgreSQL** tem tradução parcial da documentação; a de referência é em
  inglês: <https://www.postgresql.org/docs/current/>
- **SQLite** só tem documentação em inglês, mas é curta e direta:
  <https://sqlite.org/lang.html>

### 1.5 Universidades abertas 🇧🇷

- **USP / Coursera** — cursos de banco de dados dentro de trilhas de
  computação. ⚠️ Auditar é grátis; certificado é pago.
- **UNIVESP** — disciplinas de banco de dados no YouTube, gratuitas, nível
  graduação. Busque "UNIVESP banco de dados" no YouTube.
- **IFRS / IFSul** — cursos técnicos abertos com certificado gratuito
  aparecem periodicamente. Verifique a oferta vigente.

## 2. Inglês

### 2.1 SQLBolt 💰 🇬🇧 — **a melhor primeira hora de SQL que existe**

- **Onde:** <https://sqlbolt.com>
- **Duração:** ~2 h
- **Formato:** lição curta + exercício interativo, banco rodando **no
  navegador**, sem cadastro
- **Vale?** **Sim, e é o que eu recomendaria para quem tem uma tarde livre.**
  Sem vídeo, sem conta, sem enrolação: você lê três parágrafos e escreve a
  consulta. Vai de `SELECT` a `JOIN`, subconsulta e DDL.
- **Certificado:** não tem. Não precisa.

### 2.2 Mode — SQL Tutorial 💰 🇬🇧

- **Onde:** <https://mode.com/sql-tutorial/>
- **Vale?** Sim, especialmente os módulos **intermediário e avançado**: é dos
  poucos materiais gratuitos que trata funções de janela, otimização e
  análise de dado real com seriedade. Escrito por gente que faz análise, para
  gente que faz análise.

### 2.3 freeCodeCamp — Relational Database 💰 🎓 🇬🇧

- **Onde:** <https://www.freecodecamp.org/learn/relational-database/>
- **Duração:** ~150 h (a certificação inteira)
- **Formato:** projetos práticos com **PostgreSQL** de verdade, em terminal
  dentro do navegador
- **Certificado:** **gratuito**
- **Vale?** Sim, se você quer a certificação gratuita mais substanciosa da
  lista. É trabalhoso de verdade — não é clicar em "próximo".
- **Ressalva:** parte do currículo esteve em versão beta; confirme o estado
  atual antes de investir 150 h.

### 2.4 Stanford — Databases (self-paced) 💰/⚠️ 🇬🇧

- **Onde:** <https://online.stanford.edu> (matrícula via edX)
- **Autora:** Jennifer Widom
- **Nível:** universitário sério — modelo relacional, álgebra relacional,
  normalização, transações, XML
- **Vale?** **É o melhor curso acadêmico de bancos de dados disponível
  abertamente.** Se você quer o conteúdo de [60-teoria-avancada.md](60-teoria-avancada.md)
  com aulas, é aqui.
- **Ressalva:** listado a US$ 0 no Stanford Online em 2026, com matrícula pelo
  edX — **e o edX cobra pelo certificado**. Confirme antes.

### 2.5 Khan Academy — Intro to SQL 💰 🇬🇧

- **Onde:** <https://www.khanacademy.org/computing/computer-programming/sql>
- **Vale?** Para quem nunca tocou num banco, sim. Muito básico, muito gentil.
  Não vai além do essencial.

### 2.6 SQLZoo 💰 🇬🇧

- **Onde:** <https://sqlzoo.net>
- **Formato:** exercícios com dados reais (Copa do Mundo, Nobel, geografia)
- **Vale?** Como banco de exercícios, é excelente. A interface é de 2005 e não
  esconde isso.

### 2.7 Use The Index, Luke! 💰 🇬🇧 — para desempenho

- **Autor:** Markus Winand
- **Onde:** <https://use-the-index-luke.com>
- **Vale?** **Sim, e é insubstituível.** É o melhor material que existe sobre
  índices e desempenho de SQL, gratuito na íntegra, cobrindo Oracle,
  PostgreSQL, SQL Server, MySQL e DB2 lado a lado. Leia depois de
  [21-indices-e-desempenho.md](21-indices-e-desempenho.md).
- Do mesmo autor: <https://modern-sql.com>, sobre os recursos pós-1992 que
  quase ninguém usa. Também gratuito e também excelente.

### 2.8 PostgreSQL Exercises 💰 🇬🇧

- **Onde:** <https://pgexercises.com>
- 81 exercícios progressivos com solução comentada. Ótimo depois do básico.

## 3. Francês

### 3.1 OpenClassrooms ⚠️ 🇫🇷

Três cursos, em ordem de progressão:

1. **Requêtez une base de données avec SQL** —
   <https://openclassrooms.com/fr/courses/7818671-requetez-une-base-de-donnees-avec-sql>
2. **Implémentez vos bases de données relationnelles avec SQL** (MySQL) —
   <https://openclassrooms.com/fr/courses/6971126-implementez-vos-bases-de-donnees-relationnelles-avec-sql>
3. **Perfectionnez votre maîtrise de SQL** — junções, funções de janela,
   views, merge —
   <https://openclassrooms.com/fr/courses/8446806-perfectionnez-votre-maitrise-de-sql>

- **Vale?** Sim. A didática do OpenClassrooms é boa e a progressão é bem
  pensada. O terceiro é o mais valioso, porque cobre funções de janela.
- ⚠️ **Conteúdo gratuito mediante cadastro; certificado e acompanhamento são
  pagos** (assinatura). O modelo mudou algumas vezes — confirme antes.

### 3.2 SQL.sh 💰 🇫🇷

- **Onde:** <https://sql.sh>
- Referência de sintaxe em francês, gratuita, bem organizada por comando.
  Útil como consulta rápida, não como curso.

### 3.3 France Université Numérique (FUN) ⚠️ 🇫🇷

- **Onde:** <https://www.fun-mooc.fr>
- MOOCs de universidades francesas; oferta de bancos de dados varia por
  semestre. Acompanhamento gratuito, certificado pago.
- Busque por "bases de données" e "SQL".

## 4. Certificações

### 4.1 A pergunta honesta primeiro

**Certificação de SQL tem valor de mercado?**

Minha avaliação, declarada como opinião profissional:

| Situação | Vale? |
|---|---|
| Você é engenheiro químico querendo usar SQL no trabalho | **Não.** Ninguém vai pedir. Um portfólio de consultas que resolveram problemas reais vale dez vezes mais |
| Você quer migrar para carreira de dados | **Talvez**, como sinal inicial em triagem de currículo |
| Você é consultor e precisa de credencial | Sim, para o cliente |
| Você trabalha com Oracle ou Microsoft e a empresa paga | Sim, e ela paga |

**O que realmente conta em entrevista** é escrever uma consulta com `JOIN` e
janela num quadro branco, e explicar o que acontece com a cardinalidade. Isso
não se treina para prova; treina-se fazendo.

### 4.2 Certificados gratuitos

| Emissor | O que é | Custo | Valor de mercado |
|---|---|---|---|
| **freeCodeCamp** — Relational Database | ~150 h de projetos com PostgreSQL | **Grátis** | Modesto, mas o trabalho é real |
| **Kaggle Learn** — Intro/Advanced SQL | Duas trilhas curtas, BigQuery | **Grátis** | Simbólico; o nome Kaggle ajuda um pouco |
| **Curso em Vídeo** — MySQL | Curso completo em português | **Grátis** | Reconhecido no Brasil em nível iniciante |
| **Scrimba** — SQL | Interativo | Grátis (certificado incluso) | Simbólico |
| **HackerRank** — SQL Skills | Prova prática por níveis | **Grátis** | **O mais respeitado dos gratuitos** — é avaliação real de habilidade |

**Recomendação:** se você quer **um** certificado gratuito que signifique algo,
faça o **HackerRank SQL (Advanced)**. É uma prova de resolver problemas, não de
assistir a vídeo — e recrutador técnico sabe a diferença.

### 4.3 Certificações pagas

| Certificação | Emissor | Preço (13/08/2026) | Comentário |
|---|---|---|---|
| **DP-900** *Azure Data Fundamentals* | Microsoft | ~**US$ 99** (~R$ 535) | Introdutória, ampla, barata. Boa relação custo/sinal |
| **DP-300** *Azure Database Administrator* | Microsoft | ~US$ 165 | Para quem administra |
| **1Z0-071** *Oracle Database SQL Certified Associate* | Oracle | **US$ 245** (~R$ 1.320) | **A mais reconhecida especificamente de SQL.** Só vale se você trabalha com Oracle |
| **DataCamp SQL Associate/Professional** | DataCamp | Por assinatura | Marketing de plataforma; valor limitado |
| **PostgreSQL Associate** | EDB | Varia | Nicho, mas legítimo |

⚠️ **Não existe certificação oficial de "SQL" como linguagem.** Não há um
órgão certificador do padrão ISO. Toda certificação é **de um produto**
(Oracle, Microsoft, PostgreSQL) ou **de uma plataforma** (DataCamp). Quem
vender "certificação SQL internacional" está vendendo o nome de uma empresa,
não do padrão.

## 5. A trilha que eu recomendaria

Para um engenheiro químico, do zero, gastando R$ 0:

| Etapa | Recurso | Tempo |
|---|---|---|
| 1. Sentir o gosto | **SQLBolt** 🇬🇧 | 2 h |
| 2. Base em português | **Programação Dinâmica** 🇧🇷 | 10 h |
| 3. Este curso | [04](04-como-comecar.md) → [06](06-exemplos.md) → [projeto-modelo](07-projeto-modelo/) | 15 h |
| 4. Núcleo | [12](12-consulta-select.md) a [18](18-series-temporais.md) | 25 h |
| 5. Prática com dado seu | [70-pratica.md](70-pratica.md) + uma exportação real da sua planta | 20 h |
| 6. Aplicação | [30-engenharia-quimica.md](30-engenharia-quimica.md) | 8 h |

| 8. Se quiser credencial | **HackerRank SQL Advanced** | 5 h |

**Total: ~95 horas para o nível autônomo**, distribuídas em três a quatro
meses de estudo em ritmo de quem trabalha. Custo: zero.
