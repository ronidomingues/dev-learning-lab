## 2. Português — Brasil e Portugal

### 2.1 Fundação Bradesco — Escola Virtual ★★★ (grátis de verdade, **com certificado**)

**`ev.org.br`** · Brasil · gratuito · **certificado digital gratuito, com assinatura
digital e código de autenticidade**

A Escola Virtual mantém uma **Trilha de Conhecimento "Fundamentos do Power BI"**, reunindo
cinco cursos do básico ao avançado, incluindo:

- *Introdução à Análise de Dados — Microsoft Power BI* (~10–15 h);
- módulos de modelagem de dados;
- módulo avançado de Power BI.

**Por que vale o tempo:** é a melhor combinação de "gratuito de verdade + certificado
reconhecido + português do Brasil" que existe. O certificado da Fundação Bradesco tem
aceitação real em processos seletivos brasileiros, especialmente para primeiro emprego e
para comprovação de carga horária em RH.

**Limites honestos:** é conteúdo introdutório a intermediário. **Não** cobre contexto de
avaliação a fundo, desempenho, VertiPaq, PBIP/TMDL ou governança. Faça e siga adiante.

---

### 2.2 Hashtag Treinamentos — YouTube ★★ (grátis para assistir; é também isca)

**YouTube: canal Hashtag Treinamentos** · Brasil · gratuito · sem certificado

Mantêm um **Curso Básico de Power BI** em várias aulas, com edições de 2025 e 2026
publicadas. Aulas típicas: introdução, Power Query, escolha de gráficos, construção de um
dashboard completo.

**Por que vale:** didática boa, português claro, exemplos brasileiros, atualizado.
Excelente para as primeiras 10 horas.

**Seja consciente:** o conteúdo gratuito é a porta de entrada para o curso pago
("Power BI Impressionador"). Isso é legítimo — mas não confunda a aula grátis com o curso
completo.

### 2.3 Xperiun — minicurso gratuito ★★ (isca declarada)

**Por que pode valer:** bom para o "primeiro resultado na tela" e para decidir se você
gosta do assunto.

**Seja consciente:** é claramente estrutura de captação para o curso pago. O conteúdo

### 2.5 Documentação oficial em português

A documentação da Microsoft está **traduzida para português do Brasil**:

```
https://learn.microsoft.com/pt-br/power-bi/
```

**Qualidade da tradução:** boa nas seções estáveis (fundamentos, modelagem, DAX), irregular
nas seções novas — algumas páginas de 2026 ainda aparecem em inglês. A tradução automática
às vezes traduz nomes de função e opções de menu de forma inconsistente com a interface.

**Recomendação:** leia em português para aprender o conceito; confira em inglês quando a
frase soar estranha ou quando o nome de um comando não bater com a sua tela.

## 3. Inglês

### 3.1 Microsoft Learn ★★★ (grátis de verdade, é a referência)

**`learn.microsoft.com/training/`** · gratuito · com avaliações práticas gratuitas

Trilhas relevantes:

| Trilha | Conteúdo |
|---|---|
| **Get started with Power BI** | ~8 módulos, cerca de 6 horas |
| **Prepare for PL-300: Microsoft Power BI Data Analyst** | Alinhada aos objetivos do exame, atualizada para 2026, **com avaliação prática gratuita** |
| **Course PL-300T00-A** | O curso oficial de instrutor (a versão auto-guiada é gratuita) |
| Trilhas de Fabric (DP-600, DP-700) | Para o próximo passo |

**Por que é a referência:** é gratuita, oficial, alinhada ao exame, atualizada
continuamente, e a **avaliação prática** (*practice assessment*) reproduz o estilo e a
dificuldade das perguntas reais.

**Limite honesto:** é conteúdo de treinamento oficial — completo em cobertura, raso em
julgamento profissional. Ele te ensina *o que* a ferramenta faz, não *o que fazer* com ela.

---

### 3.2 SQLBI — "Introducing DAX" ★★★ (grátis de verdade)

**`sqlbi.com`** · Marco Russo e Alberto Ferrari · gratuito

Curso em vídeo de cerca de **150 minutos** que ensina DAX usando o Power BI nos exemplos.
Há também uma página "Start learning DAX for free" reunindo os recursos gratuitos deles.

**Por que vale mais que a duração sugere:** Russo e Ferrari são as maiores autoridades
mundiais em DAX, e o material gratuito deles é melhor que a maioria dos cursos pagos. Eles
explicam **contexto de avaliação** com uma clareza que quase ninguém alcança.

**Junto com:** o site `dax.guide` (referência de todas as funções, gratuita) e
`daxpatterns.com` (padrões prontos, gratuito).

**Se você só tiver tempo para um recurso em inglês, é este.**

### 3.3 Guy in a Cube ★★★ (grátis, e é o canal de manutenção)

**YouTube: Guy in a Cube** · Adam Saxton e Patrick LeBlanc · gratuito

Vídeos curtos, semanais, cobrindo novidades, problemas comuns e recursos administrativos.
Voltado para quem já usa e quer se manter atualizado.

**Por que vale:** é como o campo acompanha a cadência mensal do produto sem ler o

## 5. Certificações

### 5.1 PL-300 — Microsoft Certified: Power BI Data Analyst Associate

**A certificação de referência do campo.** Dados oficiais, consultados em 14/08/2026:

| Item | Valor |
|---|---|
| Código do exame | **PL-300** |
| Nome atual | Microsoft Certified: **Power BI Data Analyst Associate** |
| Nível | Intermediário (*Associate*) |
| Duração | **100 minutos** |
| Formato | Proctorado (presencial ou online), com possíveis componentes interativos |
| Idiomas | Inclui **português do Brasil**, além de inglês, francês, espanhol, alemão, italiano, japonês, coreano, chinês |
| Agendamento | Pearson VUE |
| **Renovação** | **A cada 12 meses**, gratuitamente, por avaliação online no Microsoft Learn |
| Preço | **Varia por país/região onde o exame é aplicado.** Fontes de terceiros citam US$ 165; a Microsoft não publica um preço único |
| Última atualização do exame | 20/04/2026 |

**Domínios avaliados:**

1. Preparar os dados
2. Modelar os dados
3. Visualizar e analisar os dados
4. Gerenciar e proteger o Power BI

**Preparação gratuita oficial:**

- trilha "Prepare for PL-300" no Microsoft Learn;
- **avaliação prática gratuita** (*practice assessment*) — reproduz estilo e dificuldade;
- **Exam Sandbox** — experimenta a interface do exame antes;
- vídeos "Exam Readiness Zone";
- guia de estudo oficial: `aka.ms/pl300-StudyGuide`.

**Política de repetição:** se reprovar, pode refazer após 24 horas; para tentativas
seguintes, o intervalo aumenta.

**Vale a pena? Minha avaliação, e é opinião:**

**Sim, com ressalvas.** A PL-300:

- ✔ é **reconhecida de verdade** pelo mercado brasileiro, e aparece em vagas;
- ✔ tem **renovação anual gratuita**, o que a mantém viva sem custo recorrente;
- ✔ força uma cobertura completa da superfície do produto — inclusive as partes chatas
  (governança, segurança) que se costuma pular;
- ✘ **não prova competência profissional**. Ela testa conhecimento da ferramenta, não
  julgamento de modelagem;
- ✘ é possível passar decorando sem saber modelar.

**Quem mais ganha com ela:** quem está mudando de carreira, quem precisa passar por
triagem de RH, e quem trabalha em consultoria (parceiros Microsoft têm metas de
certificação).

**Quem ganha menos:** quem já tem portfólio e experiência comprovável. Nesse caso, um
projeto real bem documentado vale mais.

### 5.2 DP-600 — Fabric Analytics Engineer Associate

O passo seguinte natural, dentro da trilha de dados da Microsoft.

| Item | Valor |
|---|---|
| Foco | Lakehouses, pipelines, notebooks Spark, modelos semânticos, arquitetura Fabric |
| Pressuposto | Base sólida em modelagem e DAX, equivalente à PL-300 |
| Preço | Semelhante ao da PL-300; varia por região |
| Renovação | Anual, gratuita, no Microsoft Learn |

**Diferença essencial:** a PL-300 é sobre **autosserviço analítico** (Power Query, DAX,
design de relatório, governança do Service). A DP-600 é sobre **o lado de engenharia**.

**Vale a pena?** Só se você trabalha (ou vai trabalhar) com Fabric de verdade. Certificar-se
em Fabric sem usar Fabric é decorar para esquecer. Ver
[`26-fabric-e-ecossistema.md`](26-fabric-e-ecossistema.md) §6.

**Há também a DP-700** (Fabric Data Engineer), mais para o lado de engenharia de dados.

### 5.4 "Certificadores gratuitos" — o que existe e o que vale

Aqui é preciso ser franco, porque há muita confusão.

| Emissor | Custa? | Valor de mercado real |
|---|---|---|
| **Microsoft (PL-300, DP-600)** | Exame pago | **Alto.** É a única com peso real de mercado |
| **Fundação Bradesco (ev.org.br)** | **Gratuito** | **Médio no Brasil.** Aceito para comprovação de carga horária e em triagem de RH, principalmente para nível júnior |
| Microsoft Learn (troféus, módulos) | Gratuito | **Baixo.** Serve como registro de estudo, não como credencial |
| **Coursera (audit)** | Certificado pago | Médio, depende da instituição |
| Plataformas de "certificado grátis" genéricas | Gratuito | **Praticamente nulo.** Não engana ninguém que analisa currículo |
| Cursos de YouTube | Sem certificado | Nulo como credencial; alto como aprendizado |

**Minha recomendação honesta, em ordem:**

1. **Um projeto real, público e documentado** vale mais que qualquer certificado. Um
   repositório no GitHub com um PBIP versionado, um README que explica as decisões de
   modelagem, e um relatório publicado — isso demonstra competência.
2. **PL-300**, se você precisa passar por filtro de RH ou mudar de área.
3. **Certificado da Fundação Bradesco**, se você está começando e precisa de carga horária
   comprovada — e é gratuito, então não há motivo para não fazer.
4. **Ignore** os "certificados grátis" de plataformas genéricas. Eles ocupam espaço no
   currículo sem acrescentar credibilidade.

## 6. Carreira: o que o mercado brasileiro pede

**Fatos observáveis** (vagas e comunidade, 2026):

- Power BI aparece em praticamente toda vaga de "analista de dados" no Brasil.
- **SQL é exigido junto** em quase todas. Power BI sem SQL limita o teto.
- Excel avançado continua sendo pedido.
- Python aparece cada vez mais, mas raramente como bloqueio para analista de BI.
- Fabric ainda é diferencial, não requisito, na maioria das vagas.

**Minha leitura da progressão típica:**

```
Analista de dados júnior  ── Power BI + Excel + SQL básico
        │  1–2 anos
Analista de BI            ── modelagem, DAX sólido, governança
        │  2–3 anos
Analista sênior / especialista ── desempenho, arquitetura, camada semântica
        │  2–3 anos
Engenheiro de análise     ── Fabric/dbt, DevOps, plataforma
```

**A habilidade que mais acelera essa progressão, na minha experiência, não é DAX
avançado — é modelagem dimensional mais a capacidade de conversar com o negócio.**
Técnica sem entendimento do problema produz relatórios corretos e inúteis.

**Não publico faixas salariais** porque os números que circulam são inconsistentes e
envelhecem rápido. Consulte fontes com metodologia declarada (pesquisas salariais de
associações e de consultorias de recrutamento) e considere a variação regional, que no
Brasil é enorme.

## 7. Como se manter atualizado (o problema real)

O Power BI atualiza **todo mês**. Manter-se atualizado é uma habilidade em si.

**Rotina mínima que recomendo — cerca de 1 hora por mês:**

| Frequência | O quê |
|---|---|
| Mensal | Ler o *Feature Summary* do mês na comunidade do Fabric |
| Mensal | Assistir ao vídeo mensal de demos do Power BI no YouTube |
| Semanal | Guy in a Cube (10 minutos) |
| Quando surgir dúvida de DAX | SQLBI, `dax.guide`, `daxpatterns.com` |
| Trimestral | Revisar [`65-estado-da-arte.md`](65-estado-da-arte.md) deste curso |
| Anual | Revisar licenciamento e custos ([`80`](80-custos-e-licencas.md)) |

**O que NÃO fazer:** tentar acompanhar tudo. A maior parte dos recursos mensais não afeta
o seu trabalho. Filtre por: "isso muda como eu modelo, calculo ou entrego?" Se não muda,
ignore.
